# Context: Dr. Anwesh Pandey's Portfolio

## Project Goal
To establish a simple, elegant personal portfolio page for Dr. Anwesh Pandey, a computational chemist and structural biologist specializing in multiscale modeling.

## Project Scope
The project consists of a single-page HTML file (`index.html`) implementing a responsive, modern design using Tailwind CSS. 
It showcases:
- **Hero Section**: Brief bio, current/past roles, and external links (Google Scholar, ResearchGate).
- **Academic Metrics**: Citations, h-index, i10-index, and publication count.
- **Research Focus Areas**: Highlighting specific areas like Noncovalent Interactions, MD Simulations, and Protein Electrostatics.
- **Signature Publications**: Key research papers with links to view studies.

## Technologies Used
- HTML5
- Tailwind CSS (via CDN)
- Google Fonts (Inter, JetBrains Mono)
- Material Symbols (Google Fonts)
