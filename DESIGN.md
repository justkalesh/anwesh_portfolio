# Design System

This project uses Tailwind CSS to implement a custom design system geared towards an academic, professional aesthetic.

## Typography
- **Primary Font (Body/Headings):** `Inter`
- **Secondary Font (Metrics/Labels):** `JetBrains Mono`

## Color Palette
The portfolio utilizes a tailored set of colors configured in the tailwind-config:
- **Primary:** `#000000`
- **Academic Navy:** `#0F172A` (used for main text and distinct accents)
- **Background:** `#f7f9fb` (a soft, off-white for readability)
- **Slate Gray:** `#64748B` (used for secondary text, labels)
- **Metric Blue:** `#EFF6FF` (accent for metric and focus cards)
- **Border Subtle:** `#E2E8F0`

## Layout and Spacing
- **Container Max-Width:** 1120px
- **Section Gaps:** `4rem` (mobile/md) / `8rem` (desktop/lg)
- **Gutter:** 24px

## Components
- **Top Navigation:** Sticky navigation bar providing links to main sections and a CTA to download CV.
- **Cards:** Used extensively for Research Focus Areas and Signature Publications. Styled with a subtle border and hover shadow to improve interactivity.
- **Metrics Ribbon:** A visually distinct section presenting key academic metrics (Citations, h-index, etc.).
